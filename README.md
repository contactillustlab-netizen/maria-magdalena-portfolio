# Maria Magdalena Portfolio

A polished, editorial portfolio website for Vizireanu Maria-Magdalena, built with React, Vite and React Router.

## Run locally

1. Install dependencies
   ```bash
   npm install
   ```
2. Start the development server
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal.

## Structure

- `src/components` – reusable UI components
- `src/data` – editable artwork and project data
- `src/pages` – portfolio route pages
- `src/styles` – global styles and design tokens

## Notes

- The portfolio uses a monochrome palette and placeholder assets for now.
- Artwork and projects can be updated by editing the JavaScript files in `src/data`.
